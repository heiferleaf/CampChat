# 营地聊天

Windows x64 置顶文字聊天窗。完整解压后双击 `CampChat.exe`。轻量版使用 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)，每位玩家运行同一个程序，一间房最多 8 人。

## 开始聊天

1. 游戏窗口化或无边框全屏时可以使用聊天浮层。需要把普通窗口铺满屏幕时，在营地聊天设置的「游戏窗口」列表选中它，再点「铺满屏幕」。每次展开列表都会读取当前打开的窗口。点「还原窗口」可恢复它的边框、位置和大小。游戏采用独占全屏时，Windows 外置浮层可能被盖住。
2. 房主在首页点「创建房间」，填写昵称、选择网卡，再创建房间并点「复制房间码」。把房间码发给队友。
3. 队友在首页点「加入房间」，填写昵称、粘贴房间码，再点「加入房间」。房主需要保持房间开启。
4. 在游戏中按 **Ctrl + Shift + F8** 打字，**Enter** 发送后回到游戏，**Esc** 收起并保留草稿。程序只在输入条激活期间优先接收裸 Esc。按 **Ctrl + Shift + F9** 打开房间设置。
5. 在设置里切换「底部左侧」（最近三条）和「屏幕右侧」（最新一条），也可以关闭页面和字幕动效。点击任一快捷键按钮，再按包含 Ctrl、Alt 或 Shift 的组合键即可更改。系统拒绝注册时会保留正在使用的绑定。拖动输入条左侧的拖拽柄，或拖动房间设置标题，靠近屏幕左右侧时会吸附。字幕跟随输入条。

队友发来的消息显示为可鼠标穿透的描边字幕，几秒后淡出。闲置时显示区域完全透明。房间设置可以从任务栏通知区域的「营地聊天」图标打开。

拖动主窗口的边缘或角落可调整大小，程序会记住尺寸。空间较窄时首页按钮会换行。聊天历史和表单超出显示区域时可以滚动。

## 选择网卡

- **在同一个局域网**。房主选连接到该网络的 WLAN 或以太网网卡。
- **异地用 Radmin VPN**。双方先加入同一个 Radmin VPN 网络，房主选「Radmin VPN」网卡建房。[Radmin VPN 组网说明](https://www.radmin-vpn.com/help/)
- **异地用 Tailscale**。双方加入同一个 tailnet，或由房主把自己的设备分享给队友。房主选「Tailscale」网卡建房。[Tailscale 设备共享说明](https://tailscale.com/docs/features/sharing)

房主的程序在选中的 IPv4 网卡监听 TCP 47821。连接超时时，先确认队友能访问房主在该网络上的地址，再检查房主的 Windows 防火墙是否允许此程序在对应网络上入站。房间码包含邀请凭据，发送给要加入的队友即可。聊天使用 TLS，消息历史保存在程序运行期间的内存里。

## 数据位置

快捷键、字幕偏好和浮层位置保存在 `CampChat.exe` 同目录的 `CampChat.settings.json`。写入时的临时文件也在这个目录。程序目前没有独立日志文件。请把压缩包解压到你有写入权限的目录。

## 运行开销

窗口和键盘焦点由 WPF 的 UI 线程管理。网络使用异步 TLS 读写，每位队友有独立且有上限的发送队列。房主按顺序发布消息，同一帧编码一次，积压的连接单独断开。字幕只在新消息、布局改变和到期时更新。空闲时字幕关闭计时器，消息历史最多保留 150 条。

## 从源码构建

需要 .NET 10 SDK。在包含 `CampChat.csproj` 的目录运行：

```powershell
dotnet publish .\CampChat.csproj -c Release --self-contained false -p:DebugType=embedded -o .\publish
```
